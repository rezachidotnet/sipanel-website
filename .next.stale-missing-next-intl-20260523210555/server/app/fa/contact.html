Contact & RFQ Questions

What information should I send for a project review?

Send the project type, location, estimated area, current stage, main concern, and any drawings or technical documents if available.

Can I request only a technical consultation?

Yes. You can request a review for system selection, leakage risk, shop drawings, procurement planning, or installation coordination.

Does SIPANEL handle full industrial envelope projects?

Yes. SIPANEL supports sandwich panel systems, standing seam and ZIP Tech roofing, aluminium cladding, and related industrial envelope execution.

Can I send drawings or project files?

Yes. The RFQ form can support optional file upload for PDF, JPG, PNG, and DWG files if enabled in the backend.
